About This Application

This 3D rendering application is a software project built from scratch in Java that utilizes no additional frameworks (aside from Swing, in order to display the UI). It also allows for interactive visualization of 3D objects.

Features

  • Matrix based 3D transformations(scaling, rotation, translation)
  • Support for chaining these transformations via intuitive matrix multiplication
  • Basic camera movement with correct perspective transformation
  • Drawing in real time according to the camera's position
  • Software rasterziation with a Z-Buffer
  • Support for different types of lighting (such as directional, ambiental etc) and basic shading
  • Support for texture use
  • Interactive UI to control the scene, change object properties and many other things

How to use

  • The menu bar offers a variety of features (loading objects, resetting the camera, changing scene properties etc)
  • The user can move around using the WASDEQ keys
  • The camera can also be rotated by dragging the mouse
  • An object's properties/transformations may be changed on the right side panel
